# Yandex Disk Rescue Pro

Программа для Windows 10/11 x64: скачивание файлов Яндекс Диска с автоматическими повторами, докачкой и проверкой целостности.

**[Скачать установщик для Windows](https://github.com/deathferre-cloud/yandex-disk-rescue-pro-releases/releases/download/v1.0.0/YandexDiskRescuePro-Setup-1.0.0-windows-x64.exe)**

Для работы нужен приобретённый код активации. Один код привязывается к одному компьютеру. Перенос выполняется кнопкой «Лицензия → Снять привязку устройства»; при потере старого компьютера обратитесь к продавцу.

После активации войдите в Яндекс, выберите папки, файлы или публичные ссылки и место сохранения. Загрузчик работает в фоне; текущий процесс виден на локальной странице в браузере.

Обновления устанавливаются кнопкой в программе и сохраняют настройки, лицензию, очередь и недокачанные файлы. Новые сборки могут выходить с тем же номером версии. Нужна связь с сервером активации; при её отсутствии загрузки безопасно приостанавливаются.

Здесь публикуются только готовые установщики, сведения для обновления и инструкции. Исходный код приложения закрыт.

Приложение не связано с компанией Яндекс.
